Today I turn Azure AI services into **production-ready platform capabilities**: private Azure OpenAI and Azure AI Foundry, shared access through API Management, and retrieval with Azure AI Search. Security and compliance are built into the infrastructure itself through policy-as-code, Managed Identities, Key Vault and network isolation.

- 🔴 **Global OpenShift rollout:** led **OpenShift 4.x deployments across 13 global sites**, standardized with Ansible automation

## 🛠️ What I work on

### Azure AI platform
- Private **Azure OpenAI** and **Azure AI Foundry** with RAG over enterprise documents using **Azure AI Search** and **Document Intelligence**
- **Azure API Management** as a single governed entry point, with token rate-limiting, Managed Identity auth and versioned APIs
- Async workers and **MCP servers** on Azure Container Apps with scale-to-zero

### Kubernetes on Azure (AKS)
- Private, zone-aware **AKS** clusters with system/user node pools, provisioned through reusable Terraform modules
- Blue-green upgrades with controlled traffic cutover through Application Gateway
- **KEDA** event-driven autoscaling on Service Bus queue depth
- **GitOps with ArgoCD**, with secrets centralized in Azure Key Vault

### OpenShift & Red Hat platforms
- Designed **highly available OpenShift architectures** as Principal Architect and Platform Lead
- Rolled out **OpenShift 4.x across 13 global sites** using Ansible automation and documented SOPs
- Migrated legacy workloads from **VMware and RHV to OpenShift**
- Added **Windows worker nodes** to OpenShift so .NET teams could run on the shared platform
- Built and ran **Red Hat OpenStack** private cloud integrated with **Red Hat Satellite** and **Ansible Tower** provisioning
- Centralized logging with the **ELK Stack**; supported **CP4D on OpenShift**, Apache NiFi and MongoDB workloads
- DevSecOps on the platform: threat modeling, vulnerability management and container security best practices

### Cloud foundations, IaC & security
- **Azure Landing Zones** in Hub & Spoke: VNet peering, Azure Firewall policies, Private Link, Private DNS, DNS Resolver
- Reusable **Terraform** modules delivered through **GitHub Actions** on self-hosted runners with `dev → test → prod` promotion
- **Policy-as-code** with Azure Policy for naming, approved SKUs, tagging and network isolation
- PaaS services moved behind Private Endpoints, leaving no public endpoints
